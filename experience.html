Репозиторий

Сервис управляет проектом через контролируемый жизненный цикл — от спецификации до релиза и архивации. Это не CRUD-обёртка над таблицей: переход между стадиями возможен только при выполнении бизнес-правил, а вся история переходов фиксируется явно.

30+endpoints
300+unit-тестов
6системных ролей
2уровня доступа
ЖИЗНЕННЫЙ ЦИКЛ ПРОЕКТА (FSM)
Реализовано через ProjectStage + ProjectStateMachine на библиотеке Stateless. Невалидный переход возвращает контролируемый результат, а не случайную ошибку.
АРХИТЕКТУРА (CLEAN ARCHITECTURE)
01 · API

Контроллеры и вход

Controllers, Swagger, JWT-middleware, глобальная обработка ошибок в формате problem+json

02 · APPLICATION

Use case-слой

Commands / Queries / Handlers через MediatR, валидация через FluentValidation

03 · DOMAIN

Бизнес-правила

Сущности, инварианты, FSM на Stateless, domain events (ProjectCreatedEvent)

04 · PERSISTENCE

Хранение данных

EF Core, PostgreSQL, миграции и автоматический seed при старте

ЧТО ДЕЛАЕТ ПРОЕКТ СИЛЬНЫМ
Домен не размазан по контроллерам — переходы между стадиями инкапсулированы внутри Project
FSM встроен в бизнес-логику, а не существует как декоративная диаграмма в README
Авторизация учитывает не только JWT-роль, но и роль пользователя внутри конкретного проекта
Docker-сборка гоняет 300+ тестов и не публикует образ, если хоть один упал
